## How to Use

- **QA/QC agent** adds new issues with the next sequential ID (QA-001, QA-002, ...)
- **Responsible agent** updates **Status** to `In Progress` when picked up, `Resolved` when fixed
- Resolved issues stay in the table for audit history — move row to the Resolved section
- One issue per row — never group multiple bugs into one entry

**Severity**: `Critical` · `High` · `Medium` · `Low`
**Status**: `Open` · `In Progress` · `Resolved` · `Won't Fix`
**Agent**: `frontend` · `backend` · `data-engineer` · `devops` · `qa-qc`
